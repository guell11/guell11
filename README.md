01 / ABOUT

I build AI systems from the model weights to the interface.

I'm Miguel Penha Reis, an AI engineer and researcher from Brazil.

My work sits between AI research and systems engineering: language models, latent reasoning, multimodal AI, retrieval, quantization, local inference and the software required to turn those ideas into products.

Build the model. Build the system. Understand both.

PRODUCT

I’m most interested in the point where model architecture and software architecture meet.

05 / PRINCIPLES

01 / RESEARCH FIRST
Understand the behavior before claiming the improvement. Baselines, ablations and reproducibility matter.

02 / BUILD THE WHOLE SYSTEM
A model is only one layer. Memory, inference, interfaces, storage and deployment matter too.

03 / LOCAL FIRST
Whenever practical, I prefer systems that can run locally and remain under the user's control.
