## 01 / About me

I’m **Miguel Penha Reis**, an AI engineer and researcher from Brazil.

My work moves between **research and engineering**. I like understanding what happens inside intelligent systems, then building the infrastructure, interfaces and products around those ideas.

I work with model behavior, training, fine-tuning, inference, retrieval, quantization, local deployment and complete software systems.

> ### Build the model. Build the system. Understand both.

MODEL
  │
  ├── architecture
  ├── fine-tuning
  ├── latent computation
  ├── multimodal reasoning
  │
  ▼
INFERENCE
  │

PRODUCT

## 05 / Engineering principles

<table>
<tr>
<td width="33%" valign="top">

### Research first

I care about baselines, ablations and reproducibility.

A convincing demo is not automatically a convincing result.

</td>
<td width="33%" valign="top">

### Build the whole thing

A model is only one part of an AI product.

Inference, memory, UX, storage and deployment matter too.

</td>
<td width="33%" valign="top">

### Local-first

Whenever practical, I prefer systems users can actually control.

Local models, quantization and efficient runtimes show up often in my work.

</td>
</tr>
</table>
